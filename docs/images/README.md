# Style Preview Images

Place 600px-wide PNG screenshots here, captured from the [live preview](../preview/index.html).

## Naming Convention

```
horizon.png    terminal.png    ember.png    bloom.png    heritage.png
neon.png       mono.png        terra.png    ink.png      aurora.png
```

## How to Capture

1. Run `go run ./tools/build-preview.go` from the project root
2. Open `preview/index.html` in a browser
3. For each style, select the "Activate Account" template and "Modern" client mode
4. Take a screenshot of the rendered email (600px width recommended)
5. Save as `<style-name>.png` in this directory
